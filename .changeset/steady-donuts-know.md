Release Kitia 1.0.0, a CLI and dashboard for managing external AI-resource catalogs and installing their skills, agents, and instructions into Claude Code and GitHub Copilot. Kitia keeps catalog metadata locally, leaves resource content in upstream repositories, and supports discovery, search, preview, install, update, uninstall, inventory checks, and machine-readable reports with protection for locally modified files. Includes the public npm package, documented CLI contract, and project website.

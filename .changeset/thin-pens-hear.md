Browse and manage resources in a local browser session
  - **User-Facing**
    - Run `kitia web` to view your project and user inventories in the browser.
    - Search and filter installed resources, review their metadata, and preview and audit the files on disk.
    - Browse catalog resources, inspect pinned source files with audit results, and read their GitHub commit histories.
    - Install pinned skills, agents, and instructions after reviewing the scope and destinations, then see the updated inventory.
    - Update and uninstall tracked resources. Removing unmanaged files requires two confirmations.
    - Review local conflicts before retrying an update, and see live progress for installs and inventory actions.
    - Choose a listed commit for a new installation or replace the revision of an installed resource without changing its destinations.
    - Add, edit, refresh, remove, import, and export catalog definitions from the browser, including presets and custom mappings.
    - Open the getting-started guide, see migration instructions for affected inventories, and update eligible global installations after closing the browser session.
    - Open the printed URL manually with `--no-open`, or stop the session with `Ctrl+C`.

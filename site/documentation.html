LOCAL DASHBOARDkitiNode.js 22+

Connect catalogs. Manage resources. Keep ownership local.

Kiti is a CLI dashboard for external AI artifact catalogs. Browse metadata, inspect installations, and manage project or user resources without storing artifact bodies in Kiti.

$ npx --yes github:grasdouble/Kiti

REQUIREMENTS

Run with Node.js 22 or later.

Use Git to index a source. Skills install with GitHub CLI; agents and instructions are fetched from their pinned repository commit.

WORKSPACE CONTROL

One dashboard for connected catalogs and installed resources.

Run Kiti in a project to see its project and user inventories. Press N to add a source, G to refresh one or all catalogs, and Delete to manage the selected installation. With no command, Kiti opens this dashboard by default.

npx --yes github:grasdouble/Kiti
npx --yes github:grasdouble/Kiti catalog add ai-kit https://github.com/grasdouble/AI-Kit
npx --yes github:grasdouble/Kiti dashboard
ConnectKeep several external catalogs in one local registry.
InspectSee catalog, scope, version, location, and ownership.
MaintainUpdate Kiti-managed files; review unmanaged resources without claiming their ownership.

DISCOVER

List, search, inspect, and preview.

npx --yes github:grasdouble/Kiti catalog add ai-kit https://github.com/grasdouble/AI-Kit
npx --yes github:grasdouble/Kiti list --catalog ai-kit
npx --yes github:grasdouble/Kiti search "documentation" --catalog ai-kit
npx --yes github:grasdouble/Kiti show skill create-readme --catalog ai-kit
npx --yes github:grasdouble/Kiti preview skill create-readme --catalog ai-kit

Use --kind, --group, --tag, and --status to filter. JSON discovery emits a stable array; check, doctor, and lifecycle dry runs provide versioned reports.

INSTALL

Preview before changing a target.

In the visual catalog, Copy install command works without opening a resource. It defaults to both assistants when supported, for this project. Installation options lets you change the assistant and scope inline; select Apply options to confirm or press Escape to discard changes. Opening or closing View resource and switching its tabs preserve pending choices. These choices last only while the card remains on the page, not after a reload. Copying a command does not execute it.

npx --yes github:grasdouble/Kiti install skill create-readme --catalog ai-kit --tool both --dry-run
npx --yes github:grasdouble/Kiti install skill create-readme --catalog ai-kit --tool both
npx --yes github:grasdouble/Kiti install skill create-readme --catalog ai-kit --scope user --dry-run --json

Installations default to project scope and Copilot. Choose --tool claude, --tool copilot, or --tool both. User scope places skills in the home configuration and cannot be combined with --target.

The CLI records provenance and file fingerprints, protects untracked files, and refuses to replace locally modified content unless you explicitly request --force.

LIFECYCLE

Check, update, diagnose, and remove.

npx --yes github:grasdouble/Kiti check
npx --yes github:grasdouble/Kiti doctor
npx --yes github:grasdouble/Kiti dashboard
npx --yes github:grasdouble/Kiti update --dry-run
npx --yes github:grasdouble/Kiti uninstall skill create-readme --dry-run

check reports missing or changed files and available updates. doctor is read-only; network checks are opt-in. Dashboard actions use the same operation locks, ownership checks, and conflict protections as the CLI.

Uninstalling a managed skill removes its dedicated folder and contents. Removing an unmanaged skill also removes its folder, but requires two confirmations because Kiti cannot verify its provenance; the final confirmation warns that removal is irreversible. Removing a resource required by a bundle is blocked by default.

EXTERNAL CATALOGS

Connect external catalogs from the dashboard.

Press N in kiti dashboard to add a catalog: enter its name and GitHub URL, then choose Basic or Custom. Names can use any format and are compared case-insensitively to prevent duplicates. Press R to choose and confirm removal of a user catalog; installed artifacts are not removed. Basic discovers skills, agents and instructions in known repository locations. Custom lets you map any number of skills, agents or instructions to user-chosen repository-relative paths. Instruction scope metadata is optional; when absent, instructions apply globally.

Definitions and metadata-only indexes live under ~/.config/kiti (override with KITI_CONFIG_DIR). Kiti keeps no artifact bodies. The CLI command catalog add <name> <https-github-url> performs Basic setup.

Each index is pinned to its current commit. Use catalog list and catalog remove <name> to manage sources. Run catalog refresh <name> to refresh one catalog or catalog refresh --all for every user catalog; installed artifacts stay unchanged. Removing a source definition does not remove installed resources.

CATALOG ENGINE

Local resource engine.

The local engine supports skills, agents, instructions, MCP server configurations, and bundles. External user catalogs support skills, agents and instructions; pinned skill installs use GitHub CLI, while Kiti manages agent/instruction files with the same inventory and conflict protections. Kiti's own catalog has no resource bodies. MCP and bundle setup writes native configuration for Copilot CLI and Claude Code CLI. See the MCP and bundle guide for limitations.
